# Acknowledgments

Köpri is an open-source project created through the efforts of a small team of developers from Turkmenistan and a community of contributors. This file is the only place where we publicly thank everyone who has contributed to the project.
---

## 📌 Policy: Mentions in-app vs in this file

To keep the app clean and lightweight, **only core team members** are listed inside the application UI (About screen).  
**All contributors, testers, translators and supporters** are listed exclusively in this `ACKNOWLEDGMENTS.md` file.

If you have contributed to Köpri (code, ideas, translations, bug reports, design), you will be added here — but **not** mentioned in the running application.

## 🛠 Built with

Köpri stands on the shoulders of these open-source projects:

- **Flutter** — cross-platform framework
- **Google ML Kit** — on-device Latin OCR
- **Tesseract OCR** — Cyrillic, Arabic, CJK, Devanagari recognition
- **stb_image** by Sean Barrett — native avatar resize (single-header C library)
- **Google Fonts** — Manrope & Space Grotesk typefaces
